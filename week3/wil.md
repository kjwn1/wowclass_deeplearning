마지막 네가지 모델을 가지고 테스트를 하면서 정확도를 확인하며 모델 선택하는 부분에서 생각보다 결과가 예측보다 많이 차이났었습니다. Alexnet-like가 leNet-like와 단순 cnn과 비교시 약식으로 해도 파라미터 수가 4배 정도 차이가 났기에 Alexnet-like를 사용한 케이스가 과적합 상황을 발생시키고 그걸 예시로 가져다 둔 줄 알고 처음에 validation set과 test set 정확도를 보기 전까지 train set 정확도가 그 이후 검증 시 정확도나 test 정확도에 비해 높을 줄 알았습니다. 그러나 epoch별 추이를 봐도 상승만 하고 혹시 dropout 제거 시에는 발생할까 해서 봤더니 미세하게 정확도가 낮아질 뿐 과적합이라 볼만한 상황은 나오지 않았습니다.
아직 이런 식으로 모델을 실행해보고 결과를 확인해본 경험이 부족해 과하게 파라미터가 사용된 건지 레이어가 너무 많이 쓰인건 아닌지를 확인을 못하는건지 아니면 그 외에 다른 요건이 중요하게 작용하는지 다양한 상황을 두고 한번 테스트해봐야겠습니다.
